Full 8-Step Flow

  1. Arkreen node generates solar kWh data (real IoT, DePIN-verified on Polygon/Arc)
  2. Arkreen node registers as CallGuard provider — stakes 1 USDC, sets SLA terms (30s window, 50% slash)
  3. TLAY machine (eCandle / Bitaxe) discovers provider via CallGuard registry or leaderboard
  4. Machine sends x402 call: BoAT signs EIP-3009 authorization on-device (58KB runtime, no browser)
  5. CallGuard facilitator verifies signature, opens escrow on Arc Testnet (sub-second)
  6. Arkreen endpoint responds with kWh data within SLA window (30 seconds)
  7. Auto-receipt submitted → escrow released → Arkreen earns 0.01 USDC per call
  8. If no response → machine claims timeout → Arkreen slashed → machine refunded + penalty

3 For Arkreen — Register as Provider

Any Arkreen node operator can register on CallGuard in under 5 minutes. This gives your node SLA-enforced payments from any machine caller.

Requirements

  • Arc Testnet wallet with ~2 USDC (1 USDC stake + gas)
  • Your Arkreen node endpoint URL (the API that serves kWh data)
  • Node.js installed

Setup (3 commands)

git clone https://github.com/muazzezwq/CallGuard
cd CallGuard && npm install ethers

# Set your Arkreen node wallet and endpoint
export PRIVATE_KEY=0x<your_arkreen_node_wallet_private_key>
export ARKREEN_ENDPOINT=https://<your-node>.arkreen.com/api/energy

node scripts/arkreen-register.js

After running: your node appears on the CallGuard leaderboard at arcsla.vercel.app/app/. Any TLAY machine or caller can discover and call it with SLA enforcement.

4 For TLAY — Call via BoAT

CallGuard's x402 endpoint speaks the same EIP-3009 protocol that BoAT already supports. No new cryptographic primitives needed.

HTTP Flow

# Step 1: Discover payment terms
GET https://arcsla.vercel.app/api/energy-data
→ 402 Payment Required
  { "payTo": "0x0E515...", "asset": "USDC", "maxAmount": "100000" }

# Step 2: Sign EIP-3009 and call
POST https://arcsla.vercel.app/api/call-service
  X-Machine-Id: <device_address>
  Body: { providerId, payload, from, to, value,
          validBefore, nonce, v, r, s }
→ 200 { callId, txHash, data: { kwh: 4.2, timestamp: ... } }

C pseudocode (BoAT runtime)

// BoAT on-device signing — 58KB runtime, no browser required
BoatEthTxTransferWithAuth auth = {
  .from        = machine_wallet_addr,
  .to          = CALLGUARD_FACILITATOR,   // 0x0E515...
  .value       = 10000,                   // 0.01 USDC (6 decimals)
  .validBefore = unix_now + 300,
  .nonce       = random_bytes32(),
};
BoatEthSignEIP3009(privateKey, &auth, &sig);
// POST to /api/call-service → SLA enforced, USDC held in escrow

Test without hardware

export PRIVATE_KEY=0x<machine_wallet_key>
export PROVIDER_ID=1
export PAYLOAD=kwh_now
node scripts/tlay-boat-call.js
# → prints callId, txHash, kWh response
